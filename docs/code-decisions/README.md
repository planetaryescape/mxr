# Code decisions

Each entry records a choice in the code that a reader would otherwise reverse: what was chosen, what was rejected and why, and where the code is. Product and architecture decisions stay in [the decision log](../blueprint/15-decision-log.md).

These entries replace comments in the code. When you change a choice, update its entry. When you add a choice the code can't show, add an entry here, not a comment.
